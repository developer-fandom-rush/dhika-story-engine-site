## Source authority

RAW > part-local reading > approved Story + Images > part-local analysis > cumulative trackers.

Never rewrite RAW to fit analysis.

## Core continuity rule

`previous approved state -> current evidence/delta -> current state`

Never reset:
- character state,
- relationship state,
- visual access,
- physical contact history,
- knowledge state,
- pacing/style history,
- unresolved hooks.

## Writing rule

Analysis must preserve the RAW's actual intensity and speed. It must not become a pacing restriction.

Do not:
- artificially delay a source-supported escalation,
- re-hide already-established visual access,
- convert “not yet established” into “must happen much later,”
- inject QA/consent-analysis language into story prose,
- over-justify every look, outfit, tease, reaction or desire.

Story prose and analysis prose are separate layers.
