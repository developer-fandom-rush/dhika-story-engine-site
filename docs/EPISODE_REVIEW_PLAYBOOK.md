# DHIKA Episode Review Playbook

## Goal

Review each Part so a future writer can continue from the true state without slowing, sanitizing, exaggerating or resetting the source.

## Required Part pass

For each Part:

1. Read exact RAW range.
2. Read previous approved hard-stop.
3. Read current cumulative relationship/writer state.
4. Produce faithful 40/40 local transformation.
5. Identify:
   - source facts,
   - character thoughts/assumptions,
   - supported inference,
   - unknowns.
6. Update Character Evolution.
7. Update Relationship Progression.
8. Update Reader Analysis.
9. Update Relationship History pointer.
10. Update Storytelling & Authoring Notes.

## Mandatory writer fields in Storytelling & Authoring Notes

When relevant, record:

### Pacing / escalation function
What moved, and how quickly?

### Visual / physical access delta
What was seen, touched, heard, felt, or mutually noticed?

### Repetition / recurrence
First time, repeated, habitual, callback, or escalation of a prior beat?

### Knowledge asymmetry
Who knows what? Who misreads what?

### Future-writer consequence
What must not be reset, delayed artificially, or reintroduced as a first?

## Erotic pacing analysis rule

Do not equate “gradual” with “many episodes.”

Correct model:
**beat-earned escalation**.

A major change may happen inside one Part if the micro-beat chain earns it.

## Rhythm rule

When the source uses:
dress/posture -> look -> reaction -> tiny tease -> silence/denial -> continuation,

record that pattern without inserting long justification into the story layer.

## Prediction check

Prediction is optional analytical tooling, never canon.

Predict immediate next mechanism only.
Freeze prediction.
Compare with actual.
Store:
- matched mechanics,
- partial matches,
- genuinely new author choices,
- new author-pattern lesson.
